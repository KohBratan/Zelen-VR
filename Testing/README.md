# Тестирование Zelen-VR

Содержимое папки:

- `5.1_Unit-тестирование.md` — отчёт по unit-тестированию (115 проверок).

- `5.2_Сценарное_тестирование.md` — отчёт по сценарному тестированию (28 проверок).

- `results_unit.json`, `results_scenario.json` —машиночитаемые результаты прогона.

- `harness/` — стенд: `Stubs.cs` (минимальные заглушки Unity API), `Runner.cs` (проверки), `ZelenTests.csproj`, `src/` (копия исходников проекта на момент прогона).


Воспроизведение (нужен .NET SDK, например встроенный в Unity Editor):

```
cd harness
dotnet run --project ZelenTests.csproj
```

Результат: таблица проверок в консоли и файл `results.json`.


Исходные игровые скрипты в `Assets/` во время тестирования не менялись.

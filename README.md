# Zelen-VR

Учебный VR-проект на Unity (XR Interaction Toolkit).

## Возможности

- Посадка деревьев на террейн.
- Выбор префаба и инструмента (одиночная/кистевая посадка, перемещение, удаление).
- Прозрачный призрак выбранного префаба в точке попадания луча.

## Управление

- Левый триггер — PlaceTool (посадка/применение инструмента).
- Правый грип — переключение инструмента.
- Правая вторичная кнопка — выбор следующего префаба.

## Структура

- `Assets/Scripts/PrefabSpawner.cs` — основная логика посадки и инструментов.
- `Assets/Scripts/NEW/` — скрипты навигации по меню и инвентарю.
- `Assets/Scripts/DebugRaycast.cs` — отладочный луч.

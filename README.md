# Zelen VR

Учебный VR-проект: обустройство виртуального участка — посадка деревьев, кустов, цветов и газона в VR (PCVR / Meta Quest).

## Требования

- Unity **2022.3.4f1**
- URP 14.0.8
- XR Interaction Toolkit 3.1.2
- OpenXR 1.14.1
- Input System 1.13.1

## Быстрый старт

1. Склонировать репозиторий.
2. Открыть проект через Unity Hub (версия 2022.3.4f1).
3. Дождаться импорта пакетов (первый запуск 5–10 мин).
4. Открыть сцену `Assets/Scenes/SampleScene.unity`.
5. Нажать **Play**. Без шлема включи **XR Device Simulator** в сцене.

## Управление (VR)

- **Левая рука** — инструменты (газон, деревья, кусты, цветы, клумбы).
- **Триггер** — посадить / растянуть / выбрать.
- **Grip** — растягивание клумбы / секции / газона за грань.
- **Меню** — выбор инструмента и категории.
- **Двойной клик триггером по цветку в клумбе** — выбрать конкретное растение.

## Структура скриптов (`Assets/Scripts/NEW`)

| Папка | Назначение |
|-------|------------|
| `Clumba/` | Клумба (`KlumbaTile`), посадка цветов (`PosadkaCvetov`) |
| `Sekcii/` | Секция насаждений — сетка деревьев/кустов (`SekciyaNasazhdeniy`) |
| `Gazon/` | Газон: тайл (`GazonTile`) и рисование (`RisovanieGazona`) |
| `Posadka/` | Посадка деревьев / кустов (`PosadkaDereva`) |
| `inventar/` | Модель растения (`Nasazhdenie`), подсветка, выбор |
| `Interfeis/` | Меню, выбор инструмента, навигация |

## 🎯 Запланированная функциональность

В рамках модуля планируется реализовать:

### 1. Библиотека объектов
* Одиночные деревья различных видов и кустарники.
* Настраиваемые площадки газонов и клумб.

### 2. Специальные механики модуля
* **Привязка к рельефу:** автоматическая посадка объектов точно на поверхность террейна (ровного или деформированного) без зависания в воздухе.
* **Растягивание секций:** возможность процедурно изменять длину и ширину газонов и секций с равномерным шагом распределения растений.
* **Быстрое замещение:** замена одного вида насаждения другим с сохранением координат и угла поворота.

### 3. Интеграция с общей VR-системой
* Отдельный подраздел озеленения в общем радиальном VR-меню.
* Базовые пространственные манипуляции: перемещение, вращение, масштабирование, фиксация положения (freeze) и удаление.
